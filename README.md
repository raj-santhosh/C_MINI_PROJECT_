Objective:
          Develop a menu-driven Student Record Management System in C using a singly linked list, dynamic
memory allocation, modular programming, searching, sorting, and file handling.

Executable: 
          The final application must be built as an executable named student.

Project Requirements
• The program must be menu-driven and should repeatedly display the main menu until the user chooses Exit.
• Student records must be maintained using a singly linked list.
• Each new student node must be dynamically allocated.
• The project must be divided into separate source modules.
• Student data must be saved in a file named student.dat.
• All dynamically allocated memory must be released before the program terminates.
